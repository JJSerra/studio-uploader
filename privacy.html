Studio uploader: privacy policy

Last updated: 17 October 2026

Studio uploader is a private tool used only by the owner of the YouTube channels it manages (City Atlas and TJ Home TV). It uses YouTube API Services to upload the owner's own videos, and to set their thumbnails, captions and metadata.

What data it uses

The tool acts only on the owner's own YouTube channels, with the owner's permission. It does not collect, store or share data about anyone else, and it does not use analytics, cookies or advertising.

What it stores

The only data it keeps is an OAuth token, stored in a local file on the owner's computer. Nothing is sent to any server other than Google's.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions; the local token then stops working.

YouTube and Google

This tool uses YouTube API Services. By using it you agree to the YouTube Terms of Service; see also the Google Privacy Policy.
